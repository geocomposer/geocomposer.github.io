# GeoComposer Project Page

Static single-page site (Nerfies-style, Bulma CSS via CDN), modeled after https://turbovggt.github.io/.

## Deploy to GitHub Pages
1. Create a repo named `<name>.github.io` (or any repo, using Pages from a branch).
2. Copy `index.html` and `static/` to the repo root and push.
3. Settings → Pages → deploy from branch (root). Done.
